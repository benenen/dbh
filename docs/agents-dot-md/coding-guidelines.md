# 编码约定
> 扩展 CLI 参数、错误处理和输出格式时遵循的项目契约。

- Cobra 的主命令和 `Aliases` 共用 `RunE`，在参数校验后执行操作；用 `cmd.OutOrStdout()` 与 `cmd.ErrOrStderr()` 保持输出可测试。
- SQLite、PostgreSQL、MySQL 共用会话执行逻辑；驱动差异集中在连接映射、元数据查询和 SQL 分句规则。
- 使用上游 context，给每条语句设置超时。用户自行通过 SQL 决定事务边界，避免自动重试可能已经执行的写语句。
- 结果格式维持表格、CSV 和 NDJSON；增加格式或更改 NULL 表示时同步说明兼容性。
- SQL 历史记录提交的语句，即使执行失败也可检索；终端命令和未提交片段不写入 SQL 历史。
- 对低影响修改使用既有验证；终端渲染、分句、事务、配置持久化等改动增加针对行为的验证。
